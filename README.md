This project is an API Automation Framework developed using:

REST Assured
TestNG
Maven
Log4j 2

The framework is designed for automated testing of REST APIs with support for:

Request/Response validation
Authentication handling
Logging
Reporting
Data-driven testing
Reusable utilities

Features: 
API CRUD operation testing
Request and response logging
JSON response validation
Status code validation
Authentication support
Configurable environments
Reusable framework utilities
Detailed execution reports
